# NOVA Store — Telegram-бот интернет-магазина

> **Демонстрационный проект для портфолио**

NOVA Store — самостоятельный пример Telegram-магазина для небольшого бизнеса. Бот показывает каталог, управляет корзиной, проводит пользователя через оформление заказа и уведомляет администратора.

Магазин, товары, цены, остатки, контакты и заказы вымышлены. Проект не представляет реальный бизнес, не содержит реальных клиентов, отзывов или результатов.

## Возможности

- приветствие и компактное главное меню;
- каталог из 3 категорий и 12 демонстрационных товаров;
- карточки товаров с описанием, ценой, артикулом, остатком и emoji-placeholder;
- добавление товаров в SQLite-корзину;
- увеличение и уменьшение количества;
- удаление позиции и полная очистка корзины;
- автоматический подсчёт итоговой суммы;
- FSM-оформление: имя, телефон, способ получения, город или адрес, комментарий;
- итоговый экран с подтверждением, изменением или отменой;
- транзакционное сохранение заказа и его позиций в SQLite;
- автоматическая очистка корзины только после успешного создания заказа;
- подтверждение клиенту и подробное уведомление администратору;
- 5 последних заказов пользователя;
- статусы `Новый`, `Подтверждён`, `Собирается`, `Отправлен`, `Завершён`, `Отменён`;
- команды администратора `/orders` и `/stats`;
- команда `/id` для определения Telegram ID;
- демонстрационные тексты о доставке, оплате, контактах и FAQ;
- ввод пользователя экранируется перед выводом в HTML-сообщениях.

Реальная онлайн-оплата в проекте намеренно не подключена.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Откройте папку проекта.
3. Создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

4. Активируйте окружение.

   Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   macOS/Linux:

   ```bash
   source .venv/bin/activate
   ```

5. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

6. Скопируйте `.env.example` в `.env` и заполните значения:

   ```env
   BOT_TOKEN=токен_от_BotFather
   ADMIN_ID=ваш_числовой_Telegram_ID
   DATABASE_PATH=data/nova_store.sqlite3
   ```

   ID можно узнать командой `/id`. Чтобы получать уведомления, администратор должен один раз открыть бота и нажать `/start`.

7. Запустите бот:

   ```bash
   python main.py
   ```

Папка `data` и SQLite-база создаются автоматически при первом запуске.

## Команды

Пользовательские:

- `/start` — приветствие и главное меню;
- `/menu` — главное меню;
- `/my_orders` — последние 5 заказов;
- `/cancel` — отменить текущий сценарий оформления;
- `/id` — показать Telegram ID.

Администраторские:

- `/orders` — 10 последних заказов;
- `/stats` — демонстрационная статистика по заказам и статусам.

Административный доступ определяется исключительно через `ADMIN_ID` в `.env`.

## Безопасность

- токен загружается только из `.env`;
- `.env` включён в `.gitignore`;
- токен не печатается и не попадает в логи;
- пользовательские данные экранируются перед вставкой в HTML;
- заказ и его товары сохраняются одной транзакцией;
- корзина очищается только после успешной транзакции.

## Проверка

```bash
python -m compileall -q app main.py tests
python -m unittest discover -s tests -v
```

Тесты проверяют каталог, обязательные данные товаров, импорты модулей, расчёты корзины, изменение количества, удаление, транзакционное создание заказа, очистку корзины и статистику.

## Что показать потенциальному клиенту

1. приветствие NOVA Store и главное меню;
2. категории каталога и карточку товара;
3. уведомление «Добавлено в корзину»;
4. корзину с кнопками `−`, `+` и удалением;
5. выбор доставки или самовывоза;
6. итоговый экран заказа;
7. подтверждение с номером заказа;
8. «Мои заказы» со статусами;
9. подробное уведомление администратора;
10. ответ на `/stats`.

Для портфолио используйте только демонстрационные имена, номера телефонов, адреса и заказы.
