# LUMÉ Beauty — Telegram-бот для записи

> **Демонстрационный проект для портфолио**

LUMÉ Beauty — самостоятельный пример Telegram-бота для бизнеса в сфере услуг. Он показывает полный путь клиента: от просмотра каталога до подтверждения записи и уведомления администратора.

Название салона, контакты, команда, цены и записи вымышлены. Проект не представляет реальный бизнес, не содержит реальных отзывов, клиентов или результатов.

## Возможности

- красивое приветствие и компактное главное меню;
- каталог из 5 категорий и 13 демонстрационных услуг;
- карточки услуг с описанием, длительностью и ценой;
- 4 демонстрационных мастера с разными специализациями;
- пошаговая запись на основе FSM;
- автоматическая генерация расписания на ближайшие рабочие дни;
- исключение уже занятых слотов;
- проверка имени и номера телефона;
- итоговый экран с подтверждением, изменением или отменой;
- сохранение записи в SQLite и выдача номера;
- подтверждение клиенту и уведомление администратору;
- просмотр 5 последних записей пользователя;
- статусы `Новая`, `Подтверждена`, `Завершена`, `Отменена`;
- администраторские команды `/appointments`, `/today`, `/stats`;
- команда `/id` для определения Telegram ID;
- тексты «О салоне», «Контакты» и FAQ с явной пометкой демонстрационного проекта.

## Стек

- aiogram 3
- SQLite + aiosqlite
- FSM из aiogram

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Перейдите в папку проекта.
3. Создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

4. Активируйте его.

   Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   macOS/Linux:

   ```bash
   source .venv/bin/activate
   ```

5. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

6. Скопируйте `.env.example` в `.env` и заполните значения:

   ```env
   BOT_TOKEN=токен_от_BotFather
   ADMIN_ID=ваш_числовой_Telegram_ID
   DATABASE_PATH=data/lume_beauty.sqlite3
   ```

   Узнать ID можно через команду `/id`. Чтобы бот мог присылать администратору уведомления, администратор должен хотя бы один раз открыть бот и нажать `/start`.

7. Запустите:

   ```bash
   python main.py
   ```

При первом запуске папка `data` и база SQLite создаются автоматически.

## Команды

Пользовательские:

- `/start` — приветствие и главное меню;
- `/menu` — показать меню;
- `/book` — начать запись;
- `/my_appointments` — последние записи;
- `/cancel` — остановить текущий сценарий;
- `/id` — показать Telegram ID.

Администраторские:

- `/appointments` — 10 последних записей;
- `/today` — записи на сегодня;
- `/stats` — статистика по статусам.

Доступ к административным командам определяется через `ADMIN_ID` в `.env`.

## Проверка проекта

```bash
python -m compileall -q app main.py tests
python -m unittest discover -s tests -v
```

Тесты проверяют объём каталога, наличие мастеров для каждой категории, генерацию слотов, валидацию телефона, импорт всех модулей и основные операции SQLite.

## Что показать в портфолио

Наиболее наглядные экраны:

1. приветствие LUMÉ Beauty и главное меню;
2. категории и карточка услуги с длительностью и ценой;
3. выбор мастера;
4. календарь и доступные временные слоты;
5. итоговая проверка записи с тремя действиями;
6. подтверждение с номером записи;
7. раздел «Мои записи» со статусами;
8. уведомление администратора и ответ `/stats`.

Перед публикацией скриншотов используйте только вымышленные имена, номера телефонов и данные записей.
