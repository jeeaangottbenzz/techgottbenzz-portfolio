# ELENA MOROZOVA

Демонстрационный проект для портфолио — адаптивный сайт-визитка вымышленного психолога-консультанта.

> ELENA MOROZOVA не является реальным специалистом. Контакты, цены и содержание созданы исключительно для демонстрации интерфейса.

## Запуск

```bash
npm install
npm run dev
```

После запуска сайт будет доступен по адресу `http://localhost:4174`.

## Сборка

```bash
npm run build
npm run preview
```

## Возможности

- адаптивная светлая персональная страница;
- направления обращений и форматы консультаций;
- пошаговое описание работы;
- FAQ на нативных раскрывающихся блоках;
- доступная демонстрационная форма с frontend-подтверждением;
- заметные пометки о демонстрационном характере проекта;
- SEO и Open Graph metadata.
