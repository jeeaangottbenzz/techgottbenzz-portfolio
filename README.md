# techgottbenzz — portfolio workspace

Репозиторий с демонстрационными проектами для портфолио digital-разработчика.

## Проекты

- `src/` — основной одностраничный сайт-портфолио с тремя визуальными концепциями.
- `outputs/elena-morozova-demo/` — демонстрационный сайт-визитка частного специалиста.
- `outputs/lume-beauty-bot/` — демонстрационный Telegram-бот для салона красоты.
- `outputs/nova-store-bot/` — демонстрационный Telegram-бот для интернет-магазина.

## Основной сайт

```bash
npm install
npm run dev
```

## ELENA MOROZOVA

```bash
cd outputs/elena-morozova-demo
npm install
npm run dev
```

Все проекты являются демонстрационными. В репозитории нет реальных отзывов, клиентов, результатов или секретных токенов.
